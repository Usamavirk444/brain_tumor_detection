# Brain Tumor Classification Using CNNs

A complete deep learning pipeline for binary classification of brain MRI scans — built **from scratch** using **PyTorch**, with offline data augmentation, residual blocks, and a browser-based ONNX inference demo.

## Model Architecture — BrainTumorCNN

```
Input: (Batch, 3, 224, 224)
    │
    ▼
Conv2d(3→32, 3×3) + BatchNorm2d + ReLU + MaxPool2d(2×2)
    → (Batch, 32, 112, 112)
    │
    ▼
ResidualBlock(32→64, stride=2)          [skip connection]
    → (Batch, 64, 56, 56)
    │
    ▼
ResidualBlock(64→128, stride=2)         [skip connection]
    → (Batch, 128, 28, 28)
    │
    ▼
ResidualBlock(128→256, stride=2)        [skip connection]
    → (Batch, 256, 14, 14)
    │
    ▼
Dropout2d(p=0.1)
    │
    ▼
Global Average Pooling                  [256×14×14 → 256]
    │
    ▼
Linear(256→128) + BatchNorm1d + ReLU
    │
    ▼
Dropout(p=0.4)
    │
    ▼
Linear(128→2)
    │
Output: (Batch, 2)  ← logits for [no_tumor, tumor]
```

**ResidualBlock internals:**
- Main path: `Conv2d(3×3) → BN → ReLU → Conv2d(3×3) → BN`
- Skip path: identity if dimensions match, else `Conv2d(1×1) → BN`
- Output: `main + skip → ReLU`
- Weight init: Kaiming (He) initialization on all Conv2d layers

**Total trainable parameters: 455,682**

## How to Run

### Step 1 — Prepare the dataset (offline augmentation)

```bash
cd brain_tumor_detection
python src/prepare_dataset.py
```

Options:
```
--src_dir       Raw dataset root (default: data/brain_mri)
--out_dir       Output root      (default: data/processed)
--aug_factor    Augmented copies per training image (default: 8)
--seed          Random seed (default: 42)
--val_ratio     Validation fraction (default: 0.15)
--test_ratio    Test fraction (default: 0.15)
--overwrite     Rebuild output folder if it already exists
```

This generates **1,593 training images** (177 originals × 9 copies each) using 7 augmentation techniques.

### Step 2 — Train

```bash
python src/train.py
```

The best model checkpoint is saved to `results/best_brain_tumor_model.pth` whenever a new best validation F1 is achieved.

### Step 3 — Evaluate

```bash
python src/evaluate.py
```

Prints per-class precision, recall, F1-score, and confusion matrix on the test set.

### Step 4 — Export and run browser demo (optional)

```bash
# Export model to ONNX
python demo/export_model.py

# Serve locally and open in browser
cd demo
python -m http.server 8080
# Open http://localhost:8080
```

## Data Augmentation

Applied to the **training set only**. Each training image produces 1 original + 8 augmented copies = **9 total** via the following 7-technique pipeline:

```python
transforms.Compose([
    transforms.Resize((256, 256)),               # 1. Initial resize
    transforms.RandomHorizontalFlip(p=0.5),      # 2. Mirror left-right
    transforms.RandomVerticalFlip(p=0.3),        # 3. Mirror top-bottom
    transforms.RandomRotation(degrees=20),        # 4. Rotate ±20°
    transforms.ColorJitter(                       # 5. Scanner variation
        brightness=0.25, contrast=0.25, saturation=0.1),
    transforms.RandomResizedCrop(224,             # 6. Random zoom/crop
        scale=(0.75, 1.0)),
    transforms.RandomGrayscale(p=0.05),           # 7. Grayscale simulation
])
```

Validation and test sets use **resize + normalize only** — no augmentation.

All images normalized with ImageNet statistics:
- Mean: `[0.485, 0.456, 0.406]`
- Std: `[0.229, 0.224, 0.225]`

## Training Configuration

| Setting | Value |
|---------|-------|
| Optimizer | AdamW |
| Learning rate | 5×10⁻⁴ |
| Weight decay | 5×10⁻⁵ |
| Batch size | 16 (train) / 8 (val, test) |
| Max epochs | 30 |
| LR scheduler | ReduceLROnPlateau (factor=0.6, patience=4, min_lr=1×10⁻⁶) |
| Monitor metric | Validation F1 (weighted) |
| Loss function | CrossEntropyLoss with class weights |
| Class weights | `[1404/884, 1.0]` = `[1.587, 1.0]` for `[no, yes]` |
| L2 regularization | λ=5×10⁻⁵ (via `get_l2_loss()`) |
| Dropout | 10% spatial (Dropout2d) + 40% (classifier head) |
| Device | MPS (Apple Silicon) / CUDA / CPU — auto-detected |

**Class weighting rationale:** The augmented training set has ~1,404 yes-tumor vs ~884 no-tumor images. Without weighting, the model biases toward the majority class. Assigning a 1.587× higher loss penalty to no-tumor samples forces the model to learn both classes equally.
